# Odin-Recipes

A simple recipe website built as part of [The Odin Project](https://www.theodinproject.com/) curriculum.

The website contains three different recipes, each with its own recipe page containing ingredients, instructions, and an image.

## Live Demo

[View the live websit](https://vadayivarofficial-byte.github.io/Odin-Recipes/)

## Built With

* HTML5

## Features

* Homepage with links to three recipes
* Individual recipe pages
* Recipe images
* Ingredients lists
* Step-by-step cooking instructions

## Recipes

The website includes three recipes:

1. Carrot Halwa
2. chickpea curry
3. Golden Butter Rice

## Project Structure

```text

```

## Getting Started

To run the project locally:

1. Clone the repository:

```bash
git clone https://github.com/vadayivarofficial-byte/odin-recipes.git
```

2. Open the project folder.

3. Open `index.html` in your browser.
